CheerioChip

Paste text → Clean it → Copy it anywhere

How to Use

  1. Paste your text into the Your Text box on the left.
  2. Click a button to clean it up — Remove Extra Spaces, Remove Duplicates, or Make SQL List.
  3. See the cleaned result in the Result box on the right.
  4. Click Add to Queue then press Alt+C to copy each item one by one.
