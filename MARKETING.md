# ClipStack Marketing Plan

## Overview
ClipStack is a free, local-only text manipulation tool with multi-paste clipboard functionality. Target audience: administrators, developers, data-entry professionals.

---

## Channel Strategy

### 1. Content Marketing (Low Effort, High Return)
- Create a free guide: **"5 Ways to Clean a Text List in 30 Seconds"**
- Target SEO keywords: `remove duplicates online`, `trim whitespace tool`, `convert list to SQL`
- Publish on-site; can drive organic traffic for months
- Bonus: Create a short demo GIF showing the copy-queue workflow

### 2. Reddit (Fastest Distribution)
Post with an authentic **"I built this"** angle on:
- `r/sysadmin` — admins need list cleaning
- `r/learnprogramming` — build-story resonates
- `r/PowerShell` / `r/webdev` — dev audience
- `r/Database` — SQL feature attracts DBAs
- Keep post concise; include direct link; avoid promotional language

### 3. Product Hunt (Biggest Signal / Launch Spike)
- Prepare a clean landing page with a one-line description
- Collect a small email waitlist in advance
- Launch on Tuesday/Wednesday morning (US timezone)
- Reach out to 20–30 contacts for initial upvotes
- Emphasize privacy angle: "All processing stays on your machine"

### 4. SEO — Target Long-Tail Problem Searches
Build pages around specific user queries:
- `remove duplicates from list online`
- `trim whitespace tool`
- `convert list to SQL array`
- `clipboard multi paste tool`
- `batch copy text lines`
Each page = one problem = high conversion intent.

### 5. Tool Directories (Baseline Discovery)
Submit to:
- **BetaList** (startup showcase)
- **AlternativeTo** (tool comparison)
- **StackShare** (developer audience)
- Keep descriptions feature-focused, not hype-focused

---

## Messaging & Positioning

### Core Message (Use Everywhere)
> **Paste text → Clean it → Copy it anywhere**

Why this works: it describes the workflow in 3 steps; shows the result (copy to clipboard anywhere); implies speed.

### Key Differentiators to Emphasize
- **100% local processing** — no server, no tracking, no account
- **Sequential copy queue** — one hotkey (Alt+C) cycles through a list
- **No compiler / no install / works offline**
- **Free and private by design**

## 2-Week Launch Plan (Beginner-Friendly)

### Before You Start
- You need: a free [GitHub](https://github.com) account, a free [Product Hunt](https://producthunt.com) account, and a free [Reddit](https://reddit.com) account
- Your site must be live (deployed to GitHub Pages, Vercel, or Netlify) before you can share the link

---

### Day 1-2: Deploy Your Site
**Goal: Get a live URL you can share**

1. Push your project to GitHub (create a repo, `git init`, `git add .`, `git commit -m "first commit"`, `git push`)
2. Enable GitHub Pages in repo Settings → Pages → select `main` branch → Save
3. Wait 2 minutes, your site is now live at `https://yourusername.github.io/clipstack`
4. Bookmark this URL — you will use it everywhere

**Alternative:** Drag your folder to [Netlify Drop](https://app.netlify.com/drop) for instant hosting

---

### Day 3-4: Sign Up for Directories
**Goal: Get listed so people can discover you**

1. **Submit to BetaList**
   - Go to [betalist.com/submit](https://betalist.com/submit)
   - Fill in: Name (ClipStack), Tagline (Paste text → Clean it → Copy it anywhere), Description (one sentence), Website URL
   - No email needed for basic submission

2. **Submit to AlternativeTo**
   - Go to [alternativeto.net](https://alternativeto.net)
   - Search for a similar tool like "Text Mechanic"
   - Click "Add alternative" → Fill in ClipStack name, URL, description
   - Select categories: "Online Services", "Text Tools"

3. **Submit to StackShare**
   - Go to [stackshare.io](https://stackshare.io)
   - Click "Add a Stack" → Search ClipStack → Add your URL and description

---

### Day 5-7: Prepare Product Hunt Launch
**Goal: Collect upvotes before launch day**

1. Go to [producthunt.com](https://producthunt.com) → Sign up (use your email or Google)
2. Go to [producthunt.com/post/new](https://producthunt.com/post/new)
3. Fill in:
   - **Name**: ClipStack
   - **Tagline**: Paste text → Clean it → Copy it anywhere
   - **Description**: Free, local-only text cleaner with multi-paste clipboard queue. No signup, no tracking.
   - **Website**: Your live URL
   - **Topics**: select "Developer Tools" and "Productivity"
   - **Thumbnail**: Take a screenshot of your site (Windows: Win+Shift+S, Mac: Cmd+Shift+4)
4. **Do NOT publish yet** — save as draft
5. Email 10-20 friends: "Hey, I'm launching on Product Hunt on [Day 8]. Can you upvote when I post? Here's the link: [draft URL]"
6. Prepare a short "maker comment" (2-3 sentences about why you built it)

---

### Day 8: Launch on Product Hunt
**Goal: Get to the front page**

1. Publish your Product Hunt post at **9 AM EST** (this is when PH opens for new posts)
2. Immediately post this "maker comment" explaining your story
3. Share your Product Hunt link in:
   - Twitter/X: "I just launched on Product Hunt! 🚀 [link]"
   - Your personal Facebook if comfortable
   - Any Slack/Discord groups you're in (check rules first)
4. Ask 5 friends to upvote in the first hour (votes early = higher ranking)

---

### Day 9-10: Post on Reddit
**Goal: Drive traffic and get feedback**

1. **Create a Reddit account** (if you don't have one)
2. Find the subreddits mentioned below and read their rules first
3. **Post one message per subreddit** (do not spam all at once):

**r/sysadmin**
```
Title: I built a free tool to clean text lists and copy them one-by-one (Alt+C)
Body:
I was tired of manually copying each line when updating spreadsheets and databases, so I built ClipStack.

It's fully local — nothing leaves your browser. You paste a list, click "Remove Duplicates" (or "Trim Spaces"), then use Alt+C to copy each item one-by-one.

No install, no signup. Just open and use.

Would love feedback: https://yourusername.github.io/clipstack
```

**r/webdev**
```
Title: Built a local-only text cleaner — no server, no tracking, just browser JS
Body:
Wanted a privacy-focused text tool that works offline. No analytics, no backend.

Features: Remove duplicates, trim whitespace, make SQL lists, and a copy queue with Alt+C.

Let me know what you'd add: https://yourusername.github.io/clipstack
```

**r/PowerShell** (or any relevant subreddit)
```
Title: Made a free browser tool for batch-copying lists — Alt+C cycles through items
Body:
Sometimes you just need to copy 50 product codes into a form. This tool lets you paste a list, queue it, then hit Alt+C to load each item.

All processing is local (browser JS). No data sent anywhere.

Try it: https://yourusername.github.io/clipstack
```

**Tips:**
- Do NOT say "upvote please" or "check out my project" — it sounds spammy
- Respond to every comment — engagement helps your post
- If your post gets removed, read the rules and try a different subreddit

---

### Day 11-14: Follow Up and Add SEO
**Goal: Convert visitors into returning users**

1. **Check your Product Hunt result** — note what people liked and didn't like
2. **Fix any bugs** reported in comments
3. **Add a waitlist form** (use [Formspree](https://formspree.io) free tier):
   - Create a simple form in HTML
   - Users enter email → you collect it for free
   - Use it to announce new features
4. **Create 1 SEO page** (optional but recommended):
   - Make a new file called `remove-duplicates.html` in your project
   - Copy your main page, change title to "Remove Duplicates Online — ClipStack"
   - Add a paragraph explaining when to use this feature
   - Push to GitHub — now you have 2 pages ranking for different searches
